# Dataset

This project uses the Food Delivery Sample Database provided by Database Sample.

## Dataset Description

The dataset is a synthetic food delivery marketplace dataset containing order and delivery information.

The original dataset contains multiple related CSV tables. For this project, the primary tables used are:

- `orders.csv` – Contains order details such as order ID, creation time, delivery fee, total amount, and order status.
- `deliveries.csv` – Contains delivery details such as order ID, courier ID, pickup time, delivery time, and delivery status.

The two tables are joined using the order ID.

## Data Used in Analysis

The analysis focuses on completed food delivery orders created during 2025.

After preprocessing and filtering, 251 completed orders are used for analysis and machine learning.
